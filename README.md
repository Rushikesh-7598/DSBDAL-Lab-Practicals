# DSBDAL Lab Practicals

This repository contains Python, Scala, and Java code for the DSBDAL (Data Science and Big Data Analytics Lab) practical problems.

## 📂 Structure

- `data/` – Contains datasets used in practicals.
- `python/` – Python code for analysis and ML models.
- `scala/` – Simple Scala programs for basic operations.
- `hadoop/` – Java Hadoop MapReduce applications.
- `mapreduce/` – Python-based MapReduce simulations.

---

## ✅ Problem Statements Covered

### Python
- Logistic Regression on Social_Network_Ads
- Linear Regression (California Housing Dataset)
- Iris Dataset Analysis (Label Encoding, One Hot, Dummy Encoding)
- Mall Customer Dataset Statistics
- Outlier Detection (Z-score, Scatter, Boxplot)
- Handling Missing Values
- Distributed Log File Processing using MapReduce

### Scala
- Largest Number Checker
- Print Your Name

### Hadoop Java
- Word Count MapReduce Application

---

## 📌 How to Run

Use **Google Colab**, **Jupyter Notebook**, or **Scala IDE** based on the language. For Java-based Hadoop code, you’ll need Hadoop configured locally.
